# GPU shader generation

Run `python3 modules/gpu/tools/shaders.py path/to/shaders.json` to generate the
outputs declared in a manifest. Add `--check` to compare the generated bytes
against the checked-in files. The tool downloads the pinned `sokol-shdc` for
the current host on first use. Use `--shdc /path/to/sokol-shdc` to supply that
binary locally. GLSL output is validated with glslangValidator 15.1.0.

A manifest lists source files and their `@program` names under `sources`.
It can select output backends with `slangs` and define named program variants
with `variants`. Paths are relative to the manifest. The default backend set
is desktop GLSL, GLSL ES, HLSL 5, macOS Metal and iOS Metal.

- `tables` names the generated C header. Pass a program's table and its
  entry count to `nkgpu_shader_create_from_table`. It selects the entry for
  the live renderer and copies the shader sources and metadata.
- `reflection` names the JSON file in schema `nkgpu-shader-reflection/1`.
  Set `embed_sources` to include the generated source strings.
- `header` can export source strings separately for C++ consumers.
- `include_roots` adds include directories with explicit prefixes. The
  reflection lists the source dependencies for each program variant.
